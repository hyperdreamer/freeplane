Presentation mode: what stays on screen?

All three options enter the same way (F11 / View menu) and screen-fill the graph window with no title bar. They differ only in which graph chrome stays visible. Exit (F11 or Esc) restores the exact prior window: bounds, chrome, sidebar width.

A — Canvas only recommended

Menu, toolbar, map sidebar, settings panel and status bar all hidden. Maximum graph area, zero distractions.
